APEX EDITZ WEBSITE
===================

Open index.html to run the site.

Files:
- index.html   = Home
- edits.html   = Video portfolio
- editors.html = The Editors
- style.css    = Design
- script.js    = Animations/menu/video behavior

To add your friend's photo:
1. Replace assets/images/friend.jpg with the actual photo.
2. In editors.html, replace the placeholder card with an <img> using friend.jpg.
3. Change YOUR FRIEND to the friend's real name.

To add videos:
- Put MP4 files in assets/videos/
- Copy one of the video cards in edits.html and change the filename/title.

The site is static, so it can be hosted on GitHub Pages, Netlify, Vercel, etc.
